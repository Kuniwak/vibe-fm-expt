## 確かめられなかった点

- `keyof A ?` が元のコミットのコードで P3-reparse に違反していたこと（F5 の from_own_fix を no とした根拠）は、ハーネス側が lib/publishing.js の KEY_QUERY と NULLABLE を読んで判断したもので、記録の中では実行されていない。call 3 の出力は種類×モードごとに5件で切られている。
- 失敗の記録が5件で切られるので、call 3（元のコード）で実際に違反した入力の形の全体は記録から分からない。発見は、被験側が発言で報告したものだけを記録した。
- tsc の成功は、call 19 と call 23 の出力に `error` の行がないことから読んだ（出力は grep で絞られている）。
