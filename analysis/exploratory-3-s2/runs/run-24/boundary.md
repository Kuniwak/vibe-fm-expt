- C10、C26 の「警告なし」は、call 44 の `lake build 2>&1 | grep -c warning` が0だったことに依る。キャッシュ済みのビルドで Lake が警告を再表示するかは、記録からは確かめられない（call 43 の出力は `^⚠` の行を除いて表示している）。
