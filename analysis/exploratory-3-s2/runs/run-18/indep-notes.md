## C21（#10「Lean のモデルと実際の JS が一致しているかは…確かめました」）
- 証拠の /tmp/fuzz.js は、実コードで publish→parse の往復を試したもの。モデルの出力と JS の出力を突き合わせてはいない。そこで、オラクルを「超えた」とした。ただ、モデルの定理と同じ性質を実コードで確かめることを「一致の確認」と読めば、「なし」とも取れる。
