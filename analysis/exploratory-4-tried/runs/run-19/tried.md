## 表についての補足

モデルを対象にした検査はない。
`npm test` は pretest で `build` を実行するので、そのつど `peg_src` から `peg_lib` を作り直している。
check.js と diff.js は `/tmp/verify` にあり、`home/` の下には残っていない。
そのため、各版は `tool-calls.md` の書き込みと書き換えの呼び出しから組み立てた。
T5、T17、T22、T39 の書き換えは python の `str.replace` で、一致しなくても失敗を出さない。
置き換え前の文字列は、それより前の版の文字列と一致することを確かめた。
T23 で check.js を書き換えた `sed` の置き換えが実際に効いたかは、出力の件数が T17 の 10719280 から 10720792 に増えたことからだけ分かる。
T26 の2つ目の実行で戻したのは `lib/publishing.js` だけで、`peg_lib` はもともと元のままである。
T33 の旧版 `/tmp/verify/old` は T31 で写したもので、`lib/publishing.js` は T22 の版、`peg_lib` は元の文法から作ったものである。
git の履歴では、T27 の commit が 2315522（`lib/publishing.js`、`tests/test_publishing.js`、`tests/test_roundtrip.js`）、T42 の commit が 53b53ea である。
