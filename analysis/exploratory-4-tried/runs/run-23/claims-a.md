# run-23 表2：主張と実際の対応

`claims-input.tsv` の各行を、表1（`tried.md`）の実行に結びつけた。
主張と実際が合っているかどうかの判定はしていない。
結びつけには、主張した発言の時刻より前の実行を使った。
発言より後に同じ検査を再実行したものがあれば、備考に書いた。

## 略号（表1から写したもの）

- R0、R1、R2：実コードの版。R0 は元のまま、R1 は T50 と T52 の編集を含み、R2 は R1 に T62 の編集を加えたもの。
- C1 から C6：`verification/enumerate.js` の判定。C1 PublishTotal は `impl.publish(ast)` の例外、C2 RoundTrip は再 parse の例外か `normalize(ast2) !== normalize(ast)`、C3 PublishFixed は `out2 !== out`、C4 TraverseAll は `!nesting || missed.length || entered.length !== reach.length`、C5 ModeSubset は permissive 以外で `!p || JSON.stringify(p) !== JSON.stringify(ast)`、C6 NameIsString は `/MEMBER$/.test(n.type) && typeof n.name !== 'string'`。
- I1：`inputs: 51835 x 4 modes`。I2：I1 の `ATOMS` に `"'s\\'q'"` を加えたもの、`inputs: 56684 x 4 modes`。モードは permissive、jsdoc、closure、typescript。
- K1：`normalize` が `SUFFIX_QUESTION_MARK`、`SUFFIX_BANG`、`SUFFIX_DOTS` を `PREFIX_*` に置き換えてから比べる。K2：`reachableNodes` は `meta` の下をたどらない。K3：ModeSubset の骨格ごとの最短例のうち `/\?\[\]|keyof/` に合うものを失敗に数えない。K4：ModeSubset の全件のうち `/\?\[\]|keyof/` に合うものを失敗に数えない。
- Z2：`escape_z3.py`（T28 以降の版）。文字列を `Array Int BV8` と長さで表し、各バイトは NUL 以外の任意の値、長さは `MAX_LEN` 以下。EncodeLexes は `Not(lexable(encode(s, q), q))`、DecodeEncode は `Not(equal(decode(encode(s, q), q), s))`、EncodeDecode は `lexable(s, q), Not(equal(encode(decode(s, q), q), s))`、UnescapeOrderFree は `lexable(s, q), Not(equal(decode(s, q), decode(s, q, 'swapped-unescape')))`。`sat` なら VIOLATE、`unsat` なら OK。
- `enumerate.js --broken`：4つの壊した版のそれぞれで `caught = got && (!base[inv] || got.count > base[inv].count)`。壊した版は `publisher drops PARENTHESIS`、`publisher no quote escaping`、`traverse skips children`、`mode parser diverges`。
- Z2 の `--broken`：`caught = all(v == 'VIOLATE' for v, _ in res)`。T46 からの対象は `no-backslash-escape`（EncodeLexes、DecodeEncode）と `no-quote-unescape`（DecodeEncode、UnescapeOrderFree）。
