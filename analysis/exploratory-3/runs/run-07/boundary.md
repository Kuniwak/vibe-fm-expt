## 規則の改善案（v1 のもの。1〜5 は変更1で対処済み）

1. 成果物がなく読解だけに基づく主張（C10、C4 の原因の部分）について、差の値を「超えた」と「不明」のどちらにするかを決める。
2. 「バグ」というラベルを、オラクルの差として扱うかどうかを明示する（C2、C3、C16〜C18）。run 間で読みがぶれやすい。
3. 発見の「被験側の扱い」に「報告の中で第三者（メンテナ）宛ての問いとして提示した」という値を足す。
4. オラクルの出どころに「外部の仕様・知識（JSDoc、TypeScript、JS の文法）」を足す。
5. 件数（例：「257 件」）が証拠と合わない場合の扱いを決める。差の4項目のどれにも当たらない。

- 成果物を再実行していない（規則のとおり）。数値は tmp/full.txt、tmp/rt.txt、セッション記録の道具の出力から読んだ。
- C33 の「F3 だけを直しても赤にならない」は、roundtrip.js の EXPECTED と判定の論理を読んで出したもので、実行では確かめていない。
