## 規則の文言で解釈が分かれうると感じた箇所

- **向き**：`claim_kind` が「不一致」で、挙動の記述が範囲を超えた行の向き。変更1の4 の定義では、成立側も不一致側も当たらない。変更2の3 は、`claim_kind` が「その他」の行にしか明示していない。
- **両論**：変更2の4 の「主張の文がその項目を明示しているか」の線引き。全称の否定（「以外に原因はない」「どのコードからも」）は、範囲を明示していると読むかどうかで分かれる。
- **変更2の1 の「どこかの発言」**：
  - 発見の台帳の範囲は固定発言の前だが、asserted_defect が固定発言の後の発言（#9）を含めるのかが明記されていない。
  - 見出しが断定に当たるかも明記されていない。行の台帳では見出しを各行に及ぼさないが、発見の単位ではどうするかが書かれていない。
