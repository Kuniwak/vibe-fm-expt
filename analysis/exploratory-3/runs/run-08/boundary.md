## 確かめられなかった点

- call 2 の `npm test 2>&1 | tail -15` は末尾15行だけなので、mocha のテストが全件通ったことは、npm-run-all が coverage の後に typecheck を始めたことからの推定である。tsc の終了状態は表示されていない（パイプのため、道具の結果の is_error は tail の終了状態を表す）。
- unescape_escape の公理は直接表示されていない。escape_injective が unescape_escape を使うので、その公理が [propext] に含まれると推定した。parse_publish_single／_double の公理も表示されていない（表の3定理に含まれないので、C16 の判定には影響しない）。
- モデルと実コード（addQuotesForName、文法の4規則と replace）の一致は、ハーネス側では目で読んで照らしただけで、機械的に確かめていない。規則に従い、成果物の再生はしていない。
- ランダムテストの20万回の文字列のうち、異なる文字列が何個あったかは記録にない。
