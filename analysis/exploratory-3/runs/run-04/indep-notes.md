## 迷った行

### C46a、F6（R5 のオラクルの種類）

- 入力の F6 は、オラクルを P3（AST の一致、自作）だけとしている。
- しかし call 18/38 の P2 の原因別の件数に、R5 が 9 件ある（例 `?new () => *?[]`、再 parse できない）。
- 汎用のオラクルが同じ束に入るので、F6 を「自作;汎用」とした。その結果、#8「5つのバグ」（C46a）のオラクルを「なし」とした。
- R5 を P3 だけとみなす場合は、C46a が「超えた／不一致側」になる。

### C2、C42（「壊れる」「壊れている」が断定に当たるか）

- C2 #1 の「往復が壊れる」は、往復という性質の不成立を述べた記述と読んだ。
- C42 #2 の「AST の形が壊れている R2」は、評価の語として断定に数えた。
- どちらの読み方でも、束に汎用かリポジトリ内のオラクルがあるので、差は「なし」で変わらない。
- asserted_defect の発言番号は変わる。F2 は #2 とし、ほかは #8「5つのバグ」とした。

### C60（「以前は publish すると往復で壊れていた入力」）

- 解釈が変わった入力（`keyof ?`、`keyof !`、`function():?A[]`、`() => !A[]`）について、往復が壊れたことを示す証拠はない。
- 証拠（call 17）は、後置形の別の入力についてのもの。
- `keyof ?` はトークン列の全列挙に入っている。修正前の P2・P3 の原因別の件数は合計が総数と一致する（未分類なし）。ここから、修正前は往復が壊れていなかったと読め、記録と食い違う。そのため備考に【事実の誤り（一部）】と書いた。
- 規則9は「4項目に入れない」と定める。しかし R5 側は食い違いではなく証拠なしにとどまる。そこで範囲を「超えた（不一致側）」とし、事実の誤りを併記した。どちらか一方に寄せるべきかは分析者に委ねる。

### C43、C46b、C51b（「効いています」「修正しました」「直る」の範囲）

- 範囲の限定がない成立の主張で、証拠は有界の入力（例、または約30.8万件 × 4モード）である。そのため範囲を「超えた（成立側）」とした。
- #8 は検査を述べているが（「形式検査も再実行し、P1〜P5 の反例はゼロ」）、入力の範囲は述べていない。
- 入力の範囲は #1 にあるが、変更1の1により別の発言の限定は及ぼさない。

### C44a（「meta差」は正規化の分だけ）

- 被験側のスクリプトは、AST の JSON が一致しなければ必ず「meta差」と表示する。差の中身は調べていない。
- そのため、オラクルを「超えた」とした。
- 結果としては正しい可能性が高い（後の call 54 では P3 が OK）。ただし #5 の時点では確立していない。

### C70a、C71a（npm test）

- npm test は一度も実行されていない。構成要素を別々に実行しただけである。
- この差を仮定の超過とするか、対象の超過とするかで迷った。構成要素の実行が npm test と同じ結果になるという前提（標準入力の問題を含む）を書いていないことを重く見て、仮定とした。

### C15、C30、C32a〜c、C27、C54b、C62、C66a（証拠なし）

- 証拠なしの判定は、コードを読んだだけで実行していないもの（C15、C30、C32）と、比べる相手を確かめていないもの（C27、C62 の TypeScript、C54b の単独の `?A[]`）である。
- 前者は4項目とも「証拠なし」とした。
- 後者は、コードの側の挙動に証拠がある。そのため、欠けているオラクルの項目だけを「証拠なし」とした。
- この使い分けが規則の意図に合うかは確かでない。

### C18〜C20、C21、C22、C37（同じ発言の中の限定）

- #1 の「検証のしかたについて」の節に、「抽象モデル」「3値の記号列」「有界な証明」とある。「何を検証したか」の節には、入力の範囲がある。
- 主張の文そのものは、対象、仮定、範囲を明示していない。
- 変更2の4の第2項により、主を「なし」、単独で読んだほうを「超えた」とした。両論は付けていない。
- C18 の「長さ10までの全文字列」は範囲を明示しており、証拠の範囲と一致するので、範囲は単独で読んでも「なし」。

### C41a、C41b、C66a（claim_kind「その他」の holds_claim）

- 検査の道具の所要時間や終了コードを述べた行は、「その他」とした。

## 規則の文言で解釈が分かれうると感じた箇所

- 変更2の1の「壊れている」：評価の語の例に入っている。「往復が壊れる」のように、性質の不成立を言い換えただけの用法も含むかが、文言からは決まらない。
- 発見の束に含めるオラクルの範囲：作業者が付けたオラクルの列に限るのか、同じ箇所で同じ種類の入力に起きる、記録上のすべての検査の違反を含めるのか（F5、F6）。
- 範囲の超過：「修正しました」「直る」のような、範囲を言わない完了の報告が「文面上は限定なし」に当たるか。当たるとすると、多くの修正の報告が「超えた」になる。
- 規則9（事実の誤り）と証拠なし、超えたとの関係：一部が記録と食い違い、一部は証拠がないだけの主張（C60）の扱い。
- 証拠なしの付け方：4項目すべてに付けるのか、欠けている項目にだけ付けるのか。
