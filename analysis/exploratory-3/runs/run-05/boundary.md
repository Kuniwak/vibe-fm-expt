### B1（C6、C9、C10、C12、C13、C7b）— 一部解消（変更1の 1 による）
- 前の版で迷った点：#4 の定理の文は、文面だけを見れば実コードの publish / parse について述べている。証拠は手書きの Lean モデルである。

### B2（C7a）

## 確かめられなかった点

1. `#print axioms` は3つの主定理についてだけ実行され、系 `reparse_stable` と2つの `example` の公理は表示されていない。
2. Lean の関数と JS の正規表現置換が同じ結果を返すかは、記録の中のどの成果物でも直接は確かめられていない（B3）。
3. run.env の `replies_sent=0` と、記録にある選択肢の質問への「お任せします」の回答が食い違う。選択肢の UI への回答が replies_sent に数えられない仕組みかどうかは、この作業の資料からは確かめられなかった。
4. call 8 の出力は空だが、コマンドは `lean QuoteEscape.lean 2>&1 | head -80` で、終了コードは記録にない。
5. 差分テストの列挙が範囲を覆うかについては、件数（174,762 = 2 × Σ_{k=0..8} 4^k）が理論値と一致することだけを、台帳側で確かめた。
