## 確かめられなかった点

- 乱数生成の中身は保存されていない（シード固定なし）。ある件数のうちどの形が生成されたかは記録から分からない。
- 修正後の再検査（call 28）は meta-differs を grep で除いて出力しており、修正後の実コードで meta だけの差がどの種類・件数だったかは記録にない。
- fixtures の行数は 717,440 ÷ 4 = 179,360 として計算した。ファイルごとの行数（call 4 の wc -l）とは照合していない。
- 列挙の被覆は件数（4×(40+40²+40³) = 262,560）が出力と一致することだけを確かめた。被験側は被覆を確かめていない。
- 回収した作業ディレクトリ（home/dev/jsdoctypeparser）は最終状態で、主張の時点の状態は記録（call の出力）から読んだ。成果物は実行していない。
- 「文法に沿ったランダム生成」の生成規則（enumerate.js の gen）が文法とどう対応するかは、誰も確かめていない。
- 変更1の10：被験側の修正案（後置を保つ publisher）で新しく生じた不一致は、記録に見当たらない（call 23 の実験と call 28 の再検査で、reparse-fails・ast-differs は0）。ただし call 28 では meta-differs を出力から除いており、修正で新しい meta の差が生じたかは確かめられない。
- 変更1の13：author_judgement は空欄のまま。
- 変更2の6：追加したテストは、回収したリポジトリの git diff（読むだけ）で確かめた。F1 は2件、F2 は1件（2つの expect）。F3 にはない。
