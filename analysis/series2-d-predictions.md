### Q4（4end で種類1を「検知できる」と報告した run は、S3 で種類1が4種類以上）

種類1の 4end の語は、作業者と run によって書き方が分かれる。どの run を「検知できると報告した run」に数えるかは原文の語から1つに決まらない場合があるので、書き方ごとに分けて示す。

- 両方の作業者が「検知できる」とだけ書いた run：run-27（S3 0種類）、28（6）、39（4）、40（4）、45（5）。
- 種類の行は「検知できる」で、下の行に「未検証」がある、または範囲を限った run：run-29（6）、31（6）、41（3）。
- 両方の作業者が、両方の語がある、または「一部が未検証」とした run：run-43（6）、44（6）。
- 「支持しないと判断する条件」の、種類1を「検知できる」と報告したのに S3 が3種類以下の run は、上の1つめの書き方では run-27、2つめの書き方では run-41 である。

### Q5（「未検証」と報告した種類では、正解も報告、検知されていない）

- 種類だけを「未検証」と書いた例は、run-45 の種類3だけである。種類3には正解がなく、測っていない（11.9）。
- ほかの「未検証」は、1つの種類の中の一部の範囲やモードについてのものである。確認は種類の単位で行っており、範囲ごとの正解はないので、照らせない。
