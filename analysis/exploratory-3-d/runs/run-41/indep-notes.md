## 迷った行

2. C34（「この3種類のバグはほとんど見つけられません」）：「ほとんど」を否定の量の主張として種類の主語に取り、強い読みを超えたとした。first_reading は強い。

- 追記の1は旧4の7（対象の差）を置き換えるが、検知の主張の行の gap_object を空けるのか、従来どおり埋めるのかが書かれていない。
