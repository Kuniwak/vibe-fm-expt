## 規則の文言で解釈が分かれうると感じた箇所

- 追記の1の `gap_weak`「利用者役がその種類を承認していれば…なし」
  - 承認が、主張の内容と事例の結果の一致まで保証するのかが読み取れない。C50 のように、否定の主張と承認された事例の一部の結果が食い違う場合の扱いが書かれていない。
- 追記2の2 の「明示の限定文」
  - 例の「変種は1つずつ」は、「1種類に変種1つ」の意味にも「1つずつ順に入れた」の意味にも読める。
  - 限定が、検知の主張と別の対象（基準の手確認など）についての文でも「あり」にするのかが決まっていない。
- 変更2の4（両論）の「同じ項目を証拠の内に収める限定」
  - 「延べ約100万ケース」のような、検査の範囲を明示しただけの文を限定に含めるかが読み取れない。
- 変更2の1 の「見出しや冒頭文のバグを各行に及ぼさない」と、発見の単位の `asserted_defect`
  - 行の台帳では及ぼさないが、発見の台帳では冒頭文の件数（「4つのバグ」）に含まれる発見を断定ありとした。両者の関係を明記したほうがよい。
- `later_human_table` の「合う／合わない」
  - 「表もその入力で不一致とするか」なのか、「被験側の判断（どこが欠陥か）と表が一致するか」なのかが決まっていない（F3）。
