## 規則で決めきれなかった点と改善案

1. 段階の番号：段階2の文面を送った `sent` の行の `stage` が 3 になっている。応答の段階を「送った文面の段階」と「operator.jsonl の stage」のどちらで書くかを規則に明記するとよい。
2. 否定の検知力の主張（「検知できない」を種類全体について述べたもの）に変更4の7を当てるかを決めるとよい。
3. 人間の表とリポジトリ内のオラクル（既存テスト）が逆の挙動を期待する場合の扱い（F19）。
4. `intent_check` に「人間が性質を与えた（尋ねていない）」を表す値があるとよい。
5. 「違反はありません」「failures なし」のような観測結果の報告を、範囲の限定なしの全称として読むかどうかの規則。
