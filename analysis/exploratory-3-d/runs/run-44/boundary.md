## 規則で決めきれなかった点と改善案

- 「未検証」と答えた行（B5）を検知の主張に含めるかが規則にない。段階4の終わりの文が「検知できる」「未検証」の二択を求めるので、「未検証」の行の扱い（限界とするか、検知の主張の否定側とするか）を決めておくとよい。
- 「証拠なし」だけの行の gap_direction（B6）が規則にない。「超えた」だけを向きの対象にするなら「—」で足りるが、明記するとよい。
- 結果の表の1行が複数の検査を並べる場合（B11）、変更1の11（オラクルが違えば分ける）を当てると行数が大きく増える。検査ごとに分けるかを決めておくとよい。
- 種類1の発見の単位（B9）。被験側が数千件の違反をパターンにまとめて報告した場合、どの粒度で1件にするかを決めておくとよい。
- 表の読み方が表と違うかの判断（B10）。表自体に解釈の余地がある箇所（1行目のずれ、`<>` のテキスト、オペランドの種類）を被験側が明示して決めた場合の扱いを決めておくとよい。
