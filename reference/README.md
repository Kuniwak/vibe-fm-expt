# 参照変種

条件C と C2 の独立な確認（`preregistration.md` 10章）に使う、過去のバグを現在のコード（コミット `5166cc4`）に埋め込んだ変種である。
被験側には見せない。
コンテナには入れず、`prompts/` にも置かない。

## 一覧

| 番号 | 元の修正 | 症状（確認用の入力） | 発言のバグ | 変種の内容 |
|---|---|---|---|---|
| M1 | e45ea24 | publish が TypeError（`function(...)`） | 1 | 3か所。`...` だけの可変長引数の構文木を、5a8e7f0 より前の形（`value: null`）に戻す。publish の `...` だけの分岐を消す。traverse に null の扱いを足す（M2 の症状を出さないため） |
| M2 | 70da551 | traverse が TypeError（`function(...)`） | 2 | 1か所。`...` だけの可変長引数の構文木を `value: null` に戻す |
| M3 | 56ee03a | traverse が TypeError（`new () => X`） | 3 | 56ee03a をそのまま逆適用（ARROW の子に `new` を戻す） |
| M4 | a52b947 | `typeofFoo` を `typeof Foo` と解釈 | 4 | a52b947 の文法の変更を逆にする（`typeof` と `keyof` の後の空白を必須にしない） |
| M5 | 14093e2 | `{1a: x}` を受理 | 5 | 14093e2 のうち、引用符なしのキーの規則だけを修正前（`[a-zA-Z0-9_$]+`）に戻す |
| M6 | d0b1c2b（be1df83 の直前） | `[a, b,]` が構文エラー | 6 | d0b1c2b のタプルの部分を逆にする（最後の要素を必須にする）。あわせて、空のタプル `[]` を受理し続けるよう、タプル全体の要素の並びを省略可能にする |

文法を変える変種（M1、M2、M4、M5、M6）は、生成されたパーサー（`peg_lib/`）も作り直す。
`verify-in.sh` は、各パッチを当てた後に `npm run build` を実行する。

## 元の修正との違い

- **M1、M2**：元の修正の時点では、`...` だけの可変長引数の構文木は `value: null` だった。後のコミット 5a8e7f0（2019-11-06）が、これを ANY ノードに変えた。現在のコードでは、元の修正を逆にしても症状が出ない。そのため、構文木を当時の形に戻すことで症状を再現した。M1 は publish だけが失敗するよう、traverse に null の扱いを足している。M1 の作り方は実験者に確認して決めた（publish だけの1か所の変更では、TypeError ではなく `function(...*)` という出力になる）。
- **M4**：元の修正は空白の規則（`_`、`__`、`WS`）も整理したが、変種は `typeof` と `keyof` の後の `__` を `_` に戻すだけである。
- **M5**：元の修正は、引用符付きのキーのエスケープ、数値リテラルの `+` と指数表記なども含む。変種は、引用符なしのキーの規則だけを戻した。
- **M6**：依頼では「be1df83 付近」とされていた。be1df83 はテストだけのコミットで、末尾のカンマを受理する修正は直前の d0b1c2b（「Support trailing comma」）である。元の修正のタプルの部分だけを逆にすると空のタプルも拒否されるため、要素の並びを省略可能にした。

## 確認の結果

`verification.log` は、`devenv` イメージの使い捨てのコンテナ（ネットワークなし）で、変種ごとに新しい複製に当てて確かめた記録である。
`check-symptoms.js` が6つの症状と、副作用を見る5つの入力（空のタプル、末尾のカンマのないタプル、`function(...number)` の publish、`typeof Foo`、数値のキー）を試す。

| 変種 | 現れた症状 | 副作用を見る入力 | 既存のテスト（mocha） |
|---|---|---|---|
| なし | なし | すべて変化なし | 335 件通過 |
| M1 | M1 だけ | 変化なし | 3 件失敗 |
| M2 | M2 だけ | 変化なし | 2 件失敗 |
| M3 | M3 だけ | 変化なし | 1 件失敗 |
| M4 | M4 だけ | 変化なし | 失敗なし |
| M5 | M5 だけ | 変化なし | 失敗なし |
| M6 | M6 だけ | 変化なし | 1 件失敗 |

既存のテストは、M4 と M5 を検知しない。
