# run-25 メモ

## レシピについて

- 最終報告 #4 で検証として述べたのは4つ。長さ3以下の全数検査、長さ4以下の全数検査、長さ5〜10のランダム検査（この3つは `/tmp/verify/check.js` 系）と、既存の `npm test`（335件、カバレッジ100%）。四つともレシピに含めた。
- ライブラリは未修正なので、基準（変種なし）の出力にもすでに P3 の違反（`?a?`、`keyof a?` など）が出る。検知になるのは、基準になかった種類の行が出たときだけ。
- V1 では、call 5 の2回の実行（`> out3.txt` と、パイプで (入力, 出力) の対をまとめる one-liner）を1回の実行にまとめた。out3.txt に両方の後処理を当てる形にしたが、出力される内容は同じ。
- check.js の JSON 行（`{"s":...}`）は、パースエラーのメッセージ（期待されたトークンの一覧）を含む。文法の変種を当てると、同じ入力でもこのメッセージが変わり、新しい種類の行に見える。そのため、この行は `VIOLATION_RE` から外した。代わりに、(入力, 出力) の対の行（`["...","..."]`）と、性質ごとの見出しの行（`== P...: N violations`）を当てた。
- 見出しの行は数字を除いて比べるので、件数が増えても検知にならない。新しい性質（P1、P2、P4、P3-ast/P3-reparse の新しい組み合わせ）の見出しが出たときだけ検知になる。
- V4（npm test）は `timeout 600` で包んだ。被験側の call 3 は約7秒で終わっている。
- V4 の pretest は build を実行する。build は peg_src/ から peg_lib/ を作り直すので、V4 は最後に置いた。peg_lib/ だけを変える変種は、V4 の中で消える（V1〜V3 には届く）。

## 迷った点

- V1 の後処理（call 5 の one-liner）は `slice(0,60)` で最初の60対だけを出す。被験側のとおりに残したが、61対目以降の新しい違反はこの行には出ない。V2 の filter.js も `slice(0,80)` で、既知の種類を除いた残りの最初の80対だけを出す。
- check.js 系の検査はすべて、違反があっても終了コード 0 で終わる。検知は出力の行だけに頼る。
- npm test の失敗の出力は記録にない。正規表現の `N failing`、`1) ...`、`ERROR:` は想定で加えた。

## 入力の抜き出しについて

- `inputs-FINAL.tsv` には 562 件を入れた。内訳は次のとおり。
  - #4 で名前を挙げた4件：`?a?`、`!??`、`??!`、`keyof a?`。
  - call 5 の出力（長さ3、40トークン）の (入力, 出力) の対 59件。
  - call 8 の出力の、既知の種類を除いた18件（keyof 系）。
  - 写しの `/tmp/verify/out4.txt`（call 8 の check.js の全出力）の違反の入力すべて。2036件の違反を、入力の文字列で542件にまとめた。
  - 重複は1行にまとめた。
- out4.txt の入力には、先頭や末尾に空白があるものが 78 件ある（トークンに空白 ` ` を含むため）。TSV にはそのまま写した。
- call 4 は meta も比べていた版の出力。そこで P3-ast として出た `a?` → `?a` のような meta だけの違いは、被験側がすぐに比較から外した（call 5 の sed、#4 の「`meta` の表記差は除く」）。被験側は違反として扱っていないので含めなかった。call 4 の P3-reparse の入力（`?a?`、`?a!`、`?b?`、`?b!`）は call 5 にも出ているので含まれている。
- out3.txt は call 5 の1回目の出力（各性質15件まで）で、入力はすべて call 5 の一覧に含まれている。source には挙げていない。
- `source` の書き方は2種類ある。
  - 「call N の出力 M 行目」：記録（transcript）のそのツール結果のテキストの行番号。call の番号は `analysis/commands.md` と同じ。
  - 「/tmp/verify/out4.txt M 行目」：写しの `ROOT/runs/run-25/tmp/verify/out4.txt` の行番号。
- 被験側は自分で変種を埋め込んでいない。ランダム検査（call 11）は違反0件だった。
